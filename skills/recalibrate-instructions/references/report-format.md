# Report format

Group by file. One line per change, most impactful first.

```
Recalibrated: <file>

  Removed (N):
    - <instruction summary> — <principle>

  Rewritten (N):
    - <before> → <after> — <principle>

  Flagged, needs your call (N):
    - <instruction> — <why it could not be classified>

  Kept (N)
```

Close with the token or line reduction for root files only when the number is large enough to matter.
